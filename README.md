# kastoria-dev-core.github.io

The website of Kastoria Dev Core: https://kastoria-dev-core.github.io/

A single static page, in Greek and English (the button at the top switches), with no build step:

* `index.html` the page
* `styles.css` the look, in the brand's colours, light and dark
* `script.js` the language switch
* `assets/` the logo (from the organisation's `.github/brand`) and screenshots of the apps

GitHub Pages serves it from `main`. The projects' own documentation sites stay where they are, e.g. https://kastoria-dev-core.github.io/astiko-ktel-kastorias-app/

To see it locally, open `index.html` in a browser.
